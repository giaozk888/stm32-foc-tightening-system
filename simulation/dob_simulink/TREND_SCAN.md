# 四组趋势参数：相同输入、每组10次

本轮只比较趋势滤波时间常数和有效确认时间，保持原100ms统计窗口、10/25mA等级阈值、30ms等级确认、DOB带宽、Id/电流质量门控、短缺口修复和控制参数不变。默认配置不自动采用扫描结果。

|组|趋势滤波常数|趋势确认|
|---|---:|---:|
|tau100_dwell80|100ms|80ms|
|tau100_dwell40|100ms|40ms|
|tau50_dwell80|50ms|80ms|
|tau50_dwell40|50ms|40ms|

```matlab
addpath('D:/new project/simulation/dob_simulink');
run_trend_scan('smoke');
run_trend_scan('full');
```

正式13场景×10种子，共130次Simulink模型运行。每次四个独立DWork只读分类分支同时消费同一组实际控制/DOB输入，得到520份参数评估。这不是520次独立机械模型或实机实验，也不是重复使用一份分类结果伪装四组。四路分别使用各自滤波器、状态和计时器。

`trend_scan_config.m` 冻结参数和评价规则；`run_trend_scan.m` 复用现有修复版模型，四路只接日志。所有原16项等级/特征/质量输出要求逐帧相同，只有独立趋势6项可不同。原33项控制/DOB与外部输入还要与上轮固定版逐帧对照。

结果位于 `trend_scan_results/<时间>/`：每条轨迹一份gzip CSV，包含四路完整输出、实际输入和独立外部载荷真值；指标按每场景每参数10次汇总均值、样本标准差、延迟经验P95/最大值、误激活/漏检及HIGH清除时间。每场景保存一幅代表种子的四路对照图；灰点表示当帧趋势不可用，不表示有效激活。

评价规则：

- 真值事件取独立模拟器的3.0s负载开始、4.6s卸载，斜坡也从开始变化计时，不从跨过某个电流值开始。
- 每个真事件最多匹配一次，0～800ms内的同方向新鲜标签进入可匹配。提前、重复、事件外进入计额外事件，真事件无匹配计漏检；缺口恢复时保留同一标签不重复计新进入。
- 事件前已激活不是0ms完美检测。延迟均值/P95只对成功匹配事件计算，必须同时看漏检和额外事件数量；无事件/未检出保留N/A。
- HIGH清除要求卸载前已有可信HIGH，之后首次可信退出HIGH；无HIGH状态不填0。这次四路等级不变，因此该滞留不应改善。
- 只用前5个种子选参数，再用后5个种子验证；实测短窗仍保持来源1～3与来源4～5的分离。验证失败保留100/80ms基线，不用验证结果另选参数。
- 每场景额外事件、漏检不得增加，趋势有效时间不得减少；两种实测假设的切换均值不能超过基线1.25倍。有资格者再比较匹配事件平均延迟。

这些是本批软件比较规则，不是硬件安全阈值。误激活针对合成外部载荷真值定义，不证明真实电流尖峰成因。结果只支持软件候选比较，不代表实机性能或闭环自适应收益已验证。
