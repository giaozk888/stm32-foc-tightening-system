# 五轮实测固定窗 → 每组100次软件验证

没有新硬件动作的默认入口。实机采集脚本在tools/dob_real_capture_board.py，现场独立上/关电确认及原保护不变。用户明确每组100次为软件，不是实机。

`export_batch.py`核验真实5轮/每窗192点的receipt、ELF/BIN/Flash/RAM及CSV哈希，保留原始尖峰/间隔、非因波形质量挑窗。五轮原始汇总与CSV只读归档，见data/manifest.json、window_reports.json。原始窗口不是全部8秒波形，没有独立转矩真值；1kHz任务不代表20kHz全部ADC。

`run_real_five_scan('full')`复用已编译原C/DOB和Simulink机械模型，先做measurement/torque两假设各100次OFF估计准入，再允许通过假设运行gain=.15/.25/.5与cap=.00625/.0125/.025A各100次。总Iq≤.5A，独立补偿≤.025A不变。若OFF准入失败则ON跳过，报告未通过，不能宣称已得到最佳参数。

数据分解（假设而非标定）：Iq-局部median21；速度高通仅在测量异常假设下注入。真实转矩假设中Iq残差进入机械方程和测量，不再额外强制速度残差，避免重复计算。同一192ms块保持Id/Iq/速度配对及相对时间后重网格至1ms；2.3～6.5s重复块是压力/平稳外推条件，不是实测自然尖峰频率。

种子1～60仅使用源窗1～3作调参条件；种子61～100使用独立源窗4～5作留出。100次是事件块重排、背景噪声及独立合成20～60mA等效外载变化，不是100份独立实机采样。严格准入包括既有RMSE、偏差、有效率、符号、检测≤.5s和卸载后连续100ms有效误差≤8mA的恢复≤.8s，不会因扫描需求而放宽。连续有效恢复与允许短缺口保持的反馈逻辑不同；另列“首条有效误差合格时刻”仅用于诊断，不自动替代准入。

`smoke_results/`是早期代码冒烟，不用于排名或正式通过结论：其第一次完成仅检查RMSE/偏差/有效率，缺少恢复/检测门槛。发现后正式full运行已补全严格门槛，保留冒烟产物用于审计，不把其中ON结果包装成合格的正式增益扫描。

正式结果为results/，逐次日志*.csv.gz（先写CSV、gzip确认存在后删除同名未压缩临时副本）；报告report.json冻结源文件与实际复用DLL/MEX。不会重编译或覆盖旧base/empirical证据。主机原代码/头文件哈希与旧模型原语核对；新A仅诊断代码和构建选项发生变化，不将旧历史manifest改成新源码冒充不变。

仓库根目录执行`python tools/report_dob_real_five.py`独立审计及汇总；`python tools/plot_dob_real_five.py`输出源自保存CSV的SVG曲线。纯机械模型，非电气FOC、硬件过流、IRQ/WCET和真实螺钉接触验证；没有自动应用参数或运行电机。
