## 实机结果

上电及现场条件确认后已完成单次 START，8000 次观察，按原 8 秒
RUNDOWN_TIMEOUT 自然结束，CONTACT=0；不是成功完成真实工件拧紧。

- 板端前后回读均为窗口75ms/45点/45000us、默认3τ，实际RAM τ=3。
- 原始Flash/RAM、133点整轮趋势记录及事件均保存。记录没有提前冻结。
- DOB估计有效6471/8000=80.8875%；新鲜反馈6403/8000=80.0375%。
  这是估计/反馈资格有效率，不是识别准确率或分类标签每点有效率。
- 等级改变累计7次，趋势改变累计14次，分类质量重置1次；仍有小波动标签。
- 预热标记累计977帧；源数据硬重置审计计数0，与低速/分类质量重置计数范围不同。
- Iq命令峰值0.50A，饱和累计169.008ms；DOB补偿峰值25mA，仍在原独立限幅内。
- 全轮速度峰值289.211rpm，超出240rpm的峰值49.211rpm，未触发500rpm独立超速。
- FOC最长33.2us，deadline miss=0，CCR late=0，独立故障快照VALID=0。

事件时间均相对本次START观察起点，不是真实制动电气触发时刻：

60ms记录在5.876971s捕到速度4.7rpm、状态132（饱和元信息+低速失效），
后续为状态8（预热），6.179995s时DOB已恢复有效；之后仍需分类窗口/驻留确认。
这支持后段空窗包含低速退出和重新预热，不是75ms分类窗口本身等了440ms。

34项事件写入32项环，最早2项被覆盖，保留事件从1.257008s开始；整轮趋势记录
和累计计数完整，唯一的质量重置及两个恢复端点完整保留。主机保守地不把整体事件
缺失情况下的首次代理差值升级为合格检测延迟；尤其没有真实制动起点/力矩，
不得把内部代理→标签的时间差宣称真实负载检测延迟。

结论：75ms + 3τ 组合实机可运行，记录中有估计负载上升/重载/下降标签，未触发
独立保护；仍有一次低速后的440ms趋势空窗和多次标签切换。只有一次手动制动，
无法证明比100ms更快或更准确，也不能证明每个标签都对应真实制动力变化。
标签仍仅观察，不自动影响FSM或安全限幅。
