## 拟合数值与不可信原因

模型：`mean(Iq_measured)-mean(Iq_friction_command)=Ka*delta(speed_measured)/delta(t)+b`。

100 ms /20窗：

```text
Ka = 0.00008882743186093729 A/(rpm/s)
b  = 0.04473236984 A
R2 = 0.66645934
residual RMS = 0.01545352 A
residual/speed correlation = 0.08841794
```

200 ms /10窗：Ka=.00009592581181，b=.04394494538 A，R²=.56282466。
斜率变化7.99%，但粗窗 R²未过预设.6，只能作为有限一致性证据。

关键问题是第6窗起转突增：实际窗口加速度约1067.48 rpm/s，
`mean(Iq)-mean(fric)`约.16277 A。其回归杠杆值 **.81029498**，单窗主导斜率。
这是有记录的数据，不因它影响结果就删除；只能做留一敏感性诊断。
依次留出每个窗口，Ka 范围 **-.00000841715 .. .00009347519**；
留出第6窗斜率变为负值，表明其它平稳跟踪窗口不足以独立支持正惯性系数。
不能以初次100ms拟合 R²>.6 就当作已经可靠辨识。

原采集 receipt 保留最初报告不覆盖；复核报告：
`tmp/ka-ident-first-run-fit-review.json`。
离线工具新增单窗主导/留一斜率不稳诊断，当前报告 trusted=false，所有四档建议禁用。
它只影响报告与候选推荐，不修改任何板端控制/保护阈值或已刷固件。

算术上的 .5/.75/1/1.25 倍为 .00004441372 / .00006662057 / .00008882743 /
.00011103429 A/(rpm/s)，**没有运行、没有应用，不是已批准的标定参数**。
正向一个启动过程也不能声称已辨识反向 Ka。

结论：完成数据采集，尚无可信最终 Ka。下一步可人工授权重复采集和更多独立加减速段，
检查滤波/实测电流与速度时间对齐，不能靠挑选低残差窗口或降低标准完成标定。
最终有效 Ka 的 A/B 评价仍用整个参考加速段 speed_ref-speed_meas 跟踪误差，
不按 stable 确认时刻排名。
