# BEMF 磁链倍率诊断：每档三次

## 目的与状态

比较现有候选 ψf 是否使反电动势前馈过强。先准备独立诊断 A；此文不是实测结果，不自动把胜出值写入控制或 B。使用用户选定的 Ka 0.25 倍 = 0.000046875 A/(rpm/s)，其余条件沿用前次空载实验。

## 五档与顺序

| 倍率 | 有效 ψf Wb | 240 rpm 理论 Vq_ff V（p=10） |
|---|---:|---:|
| 0 | 0 | 0 |
| 0.25 | 0.00017433 | 约 0.04381 |
| 0.5 | 0.00034866 | 约 0.08763 |
| 0.75 | 0.00052299 | 约 0.13144 |
| 1.0 | 0.00069732 | 约 0.17526 |

固定顺序：0→25→50→75→100→100→75→50→25→0→0→25→50→75→100（百分比），每档三次。只改变 BEMF 倍率；不调整 PI、摩擦补偿、加速度前馈、角度、相序、采样、IRQ 或保护。各轮保留原 8 秒空载 rundown 自然结束和 12 秒板端限时，不强制 CONTACT，不报告 tightening OK。

公式：`Vq_ff = omega_e * 0.00069732 * gain_percent / 100`，ωe 沿用有符号实测电角速度 rad/s，前馈仍位于原统一电压限幅之前。零档使用 OFF；100% 与原前馈公式相同。

## 软件与构建

- A 专用选项 `FOC_BEMF_GAIN_DIAG`，默认 OFF；独立预设 `BemfFluxGainDiagnostic` 继承 `TighteningKa025Candidate`，BEMF 上电默认 OFF、倍率默认 0，无自动启动。
- 命令 `MOTOR TEST BEMF GAIN 0|25|50|75|100` 仅在原空闲/输出关闭门禁内生效。严格拒绝其他数字、负数、尾随垃圾和运行中修改；设置倍率本身不使能驱动或 BEMF。
- 返回 `GAIN_PCT` 与 `EFFECTIVE_PSI_NWB`；批次在每次 START 前验证回读，停机后独立从 RAM 核对倍率，并验证运行中 coherent 电压帧符合所选公式。
- 运行器 `tools/bemf_flux_gain_batch.py`：默认只读文件；执行 15 轮要求新鲜整组人工上电/现场确认。每轮重新校准、时序预检，使用原 START/STOP/SAFE/完整抓取路径；独立保护或证据失效立即停止，不重试。不在通电期间刷写固件。
- BIN 212288 B，SHA256 `c644472b27d6a9dbc74c95a9219b06e165aafd146ea411bdd77a520fc9b3fcf7`。
- ELF SHA256 `40f1492e9dd19fa197e0272eb1ee744a017ddfc03ac93a8078a25a5c85738e6b`。
- Flash 212288/229376 B；RAM 124104/131008 B。相对正常 A 增加 Flash 704 B、RAM 80 B；线程堆栈/堆配置未减小。
- 原正式 B 与正常 A 历史二进制保留。B 固件没有此选项。

- 新批次：6 项，覆盖五档各三次、缺失 settling 不伪造为零、确认门禁、严格倍率回读、故障不继续及原受保护运行 owner 复用。

- 既有 Ka025 候选与脚本：11 项。
- 既有 speed 系列：81 项。
- 对比诊断与正常 A 的预处理函数：ADC/PWM pipeline、timer-health、power stage、encoder angle/speed、MotorControlTask/TighteningTask 等保持相同；IRQ、ADC timing、encoder DMA、zero calibration、FSM 对象逐位相同。
- 编译 warning 集合与原正常 A 相同；保留历史未使用符号及 RWX 链接告警，没有新增告警。

## 数据与判断

每轮保存 Flash/RAM、完整 receipt 及哈希、板端 8000 点 AFF/FRIC 聚合。各组报告加速 MAE（主指标）、匀速 MAE、超调、Iq 命令/实测峰值、PI/积分器峰值、Iq 饱和、FOC wall、deadline miss、CCR late、actual margin；报告每组三次均值、样本标准差和范围。

电压帧仍是相同 2 Hz 稀疏查询，不能称为全速率电压峰值或饱和时长。若 UART 丢字节，单独报告；聚合指标以独立 RAM/板端计数验证，不能编造缺失帧。stable-motion 判据时间不替代加速误差或编码器物理启动时间。

若较小倍率加速/匀速误差及超调都更好，只能支持“这个工况的有效前馈量可能偏大”，不是直接证明物理 ψf 偏大或精确标定 Ke。ψf 仍是基于命令电压模型的未外部校准候选；每档三次也不等于充分统计显著性。

## 人工步骤

1. 已确认 12 V 关闭、MCU 供电、转轴解锁且空载固定、有防护；只更新非活动 A，保留 B 回退并完整回读。
2. 另行确认上电、0.5 A 限流、无报警、整组全程在场可立即断电后，才执行本固定 15 轮批次。
3. 结束后确认关断证据并请人工关闭 12 V，再恢复原 B 启动选择；不自动应用倍率或追加测试。
