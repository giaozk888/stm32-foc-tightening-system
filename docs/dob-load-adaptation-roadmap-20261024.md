## 现有边界

- `mechanical_dob_monitor`：输出带时间戳、有效位及质量原因的 A 等效扰动；机械速度为 rad/s。不能将其直接称为 N·m。
- `dob_feedback_candidate.h`：当前固定增益 0.25，独立补偿限幅 min(0.025 A, 5% Iq limit)，再经过统一总 Iq 限幅和原 AW。控制消费前一已完成 DOB 帧。
- `tightening_intent_fsm`：输出 ControlIntent，接触使用已建立运动、速度下降、电流需求和持续时间；没有 DOB 决策输入。
- `speed_scurve`：接受目标速度变化，保留速度及加速度连续性；不能每次更新目标都 Reset。
- 正常 A 的 CONTACT 为 20 rpm；DOB 观察下限 10 rpm，但新鲜补偿仍要求至少 20 rpm。DOB 无效不能等价为零负载，也不能成为永远禁止原 FSM 接触的条件。
- DOB 带宽 2 Hz、有效预热约 398 ms。突变检测受带宽、质量和数据延迟约束，不能承担硬过流、快速停机或确定扭矩保护。
- Simulink 目前验证机械模型及外环，未覆盖实际电气 FOC、ADC/SVPWM、开关尖峰成因、硬保护执行延迟和 CPU WCET。

## 建议数据流

```text
上一已完成 DOB 快照 + 同步速度/电流/阶段/质量
                      |
                 LoadFeatures（只读特征）
                      |
                 LoadDecision（驻留/迟滞/失效状态）
                      |
原 FSM -> base ControlIntent -> LoadScheduler -> S-curve -> speed PI
                                                       + 原前馈
                                                       + 有界 DOB 补偿
                                                       -> 统一 Iq 限幅
```

保护/STOP 继续直接优先关断，不等待以上模块。调度器不写 PWM、PI 参数、电流反馈、保护阈值或 FSM 内部 state。

所有模块使用明确的输入时间戳和 update counter。每个外环周期最多更新一次；不要在多个任务重复修改同一参考。发布调度结果采用有版本快照，下一明确周期消费，不形成同拍代数环。

拟议最小契约：

- `LoadEvidence`：source_us、age_us、valid/status、disturbance_a、direction、机械速度及阶段。
- `LoadFeatures`：方向归一化阻力、窗口变化率 A/s、有效时间覆盖率、窗口时长及质量状态。`direction * disturbance_a` 用于比较正反转阻力，保留原有符号的扰动用于补偿；不要对绝对值做全部判断。
- `LoadDecision`：UNKNOWN/LIGHT/RISING/HIGH/RELEASING、进入时刻、原因。它们是负载分类标签，不是新增 tightening 流程状态。
- `AdaptiveIntent`：base/applied 速度、工作 Iq 上限、补偿增益及原因；独立保留原始 FSM 意图，避免“实际应用值”回写污染配方。

## 阶段 1：只观察与分类

先在软件目录增加独立纯 C 分类器和主机测试，挂入 Simulink；不接固件控制出口。对可信扰动计算小窗口趋势及持续时间，避免直接差分有噪声的 DOB 数值。趋势滤波、迟滞和驻留长度按既有 2 Hz 动态设计，训练/验证数据分离，不先随意指定轻/重负载电流门槛。

被隔离点不进入特征滤波、趋势回归或有效计时。短缺口保留特征记忆但不获得有效驻留时间、不触发新决策；长缺口转 UNKNOWN，恢复须重新确认。分类层本身不清空底层观察器，不延长既有补偿保持规则。

日志包含原始 dhat、质量/age、有效覆盖率、阻力及趋势、分类及原因。已有五次无载短窗可检验误判/异常处理，不能单凭它们确定真实重负载或接触门槛。

通过条件：隔离点不污染统计；单尖峰不导致持续 HIGH；负载正反转方向正确；长缺口为 UNKNOWN；合成阶跃/斜坡/卸载分类与独立场景真值相符，并报告延迟和误报。

## 阶段 2：只调整速度

在仿真副本中只允许 RUNDOWN 的有效分类改变目标速度，RUNDOWN_START、TIGHTEN、HOLD 不启用调度。原 PI、Ka、摩擦、BEMF、DOB 增益 0.25、工作 Iq 上限保持不变。

目标位于预先配置的低速目标与原配方 rundown 速度之间，第一版只降速；不因轻载提升到超过原配方。通过原 S-curve 生成 speed_ref/accel_ref，不直接改最终 speed_ref、不重置轨迹。负载趋势连续成立才降速；解除使用迟滞和驻留，通过原 S-curve 恢复。

必须先覆盖主动降速导致误 CONTACT 的回归。现有接触条件有相对峰速下降判据，主动降速同样可能满足。记录降速来源、base/shaped reference 及跟踪误差；在仿真中验证一种明确的“主动减速期间接触资格”规则，同时保留真实堵转/故障和总时限路径，禁止为了避免误触发直接无限屏蔽接触。不能把未修改的 CONTACT 与任意低速调度直接组合上板。

DOB 短暂无效时冻结负载分类决定，不依据假零负载恢复高速；长时间无效取消自适应权限，采用原配方或已定义的保守回退，并经 S-curve 平滑转移。具体回退行为需在接触/释放场景中固定后再实现。

通过条件：目标及 jerk/acceleration 连续有界；无主动降速误 CONTACT；无新超速/超流；和相同速度调度但无 DOB 补偿的对照分开评价。原跟踪误差降低不能单独证明性能变好，因为目标已经降低；同时比较作业时间、绝对速度跌落、接触速度和电流。

## 阶段 3：再调整 DOB 补偿增益

保持已通过的速度策略，工作 Iq 上限仍固定。第一版仅在 0～0.25 范围调度，先验证有质量保障的启用、淡入和失效退出；不因仿真 0.5 更好就提升正常上限。此前空载各十轮不支持直接替换为 0.5。

调度输出有效增益，仍复用原 ±25 mA/5% 补偿限幅、0.25 A/s 补偿斜率、2/5/20 ms 新鲜/保持/失效规则和总 Iq AW；不要在调度层再加第二份 DOB 电流。增益变化与有效标志分离，过期估计不得借新增益延长寿命。

通过条件：无载误补偿不恶化；负载突加、卸载、异常、正反转下无错误方向或振荡；逐帧补偿/总电流限幅均满足。单独对照固定 0.25、调度增益及 DOB OFF，避免多变量一起变化无法归因。

## 阶段 4：工作 Iq 上限调度

先仅在仿真中验证“工作限幅”，不修改独立安全限幅。速度模式工作上限必须 <= 配方上限且 <= 原 0.50 A；TIGHTEN/HOLD 保留原配方，不用速度扰动估计代替扭矩控制。

第一版优先维持 0.50 A；确认需求后才加入低负载节制及受控恢复。增加工作限幅变化率、最小驻留和总输出 AW 测试。降低上限后当前命令仍须立即满足限幅；不能为了平滑而暂时越界。

重点回归：当前观察器会因饱和失效，工作上限降低可能造成“饱和 -> DOB 无效 -> 调度改变上限”的循环。必须显式处理饱和期间的调度权限和回退，不能忽略饱和质量位，也不能靠升高硬件保护阈值解决。

通过条件：每帧有效工作限幅不超过基线上限；积分器无异常冻结/累积；无上限来回跳动；分类失效或卸载不会导致意外加速。

## 阶段 5：DOB 辅助 FSM

最后增加非强制的 `LoadEvidence` 辅助输入，不允许调度器直接赋值 FSM 状态。先 shadow 记录“若启用会如何转换”，再在仿真中作为接触的附加证据。

CONTACT 保留已建立运动、速度下降、电流需求和驻留条件；DOB 仅提供额外置信度或保守降速建议，不单独决定 CONTACT、DONE 或卡死。UNKNOWN、预热及低速失效回退原资格规则，不永久阻塞原流程。主动减速来源与负载减速分开记录。

无工件和独立扭矩真值时，只能验证软件转换正确性，不能证明区分“正常拧紧/异常卡死”的物理阈值正确，也不能将纯机械负载模型的完成事件冒称真实拧紧验收。

## 软件验证矩阵与交付顺序

1. 先实现阶段 1 的 C 特征/分类器、固定种子单元回归和 Simulink 接口；A/B 固件默认不接入。
2. 为阶段 2 加入由模拟器独立产生的接触位置、硬/软接头、负载阶跃/斜坡/卸载、卡滞及无接触场景。定义接触力学假设，保留 ground truth，不能从 DOB 反推真负载。
3. 每次只开放一个调度出口，保留固定基线。每组 100 个成对随机种子，OFF/ON 使用同一噪声、扰动和模型参数；训练与留出验证按原始实测轮次分离，避免同一短窗泄漏到两组。
4. 扫描机械模型/电流执行器假设、噪声强度、尖峰、持续 Id 异常、长短缺口和反转；保留原始失败，不选择性删点。
5. 每组输出 CSV、均值/标准差、配对差及改善/恶化次数；同时报告质量覆盖率、误 CONTACT/漏 CONTACT、循环时间、速度误差、电流峰值、饱和时间和恢复。验收准则在运行前固定，不根据结果改阈值。
6. 软件通过后，才准备显式 opt-in 的候选 A：核对 RAM/Flash 预算、外环耗时和 FOC deadline/CCR late。现有诊断镜像空间接近上限，不能无预算叠加大日志环；复用或替换专用 trace，不修改生产日志默认值以掩盖占用。
7. 板测需另行人工确认；先 shadow，再单项接入，最后组合测试。未通过实机交叉验证前，保持现有正常候选默认行为及物理 B 不变。

本方案不自动创建新构建、运行 100 次矩阵或刷写硬件；下一实现工作明确从阶段 1 开始。
