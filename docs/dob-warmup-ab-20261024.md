# DOB 5τ / 3τ 单镜像对照候选

仅候选 A；默认仍为 5τ。原 B、boot 和持久配置不作修改。

## 改动与边界

`FOC_DOB_WARMUP_AB` 默认关闭，新 preset `DobWarmupAbCandidate` 单独启用。
只把 `elapsed_s * bandwidth_rad_s >= 5` 的有效标记门槛做成可选 3 或 5。
2 Hz 观测器极点、滤波器、机械模型和估计值公式完全相同。
累计**有效更新**约 239 ms / 398 ms；缺样、低速及质量恢复仍会增加实际空窗，
所以不承诺实际空窗直接缩短为 239 ms。

3τ 的一阶初始误差残留约 5%，5τ 约 0.67%，这是较早接纳估计的代价，
不是提高滤波带宽。保持原初次方向确认、10 rpm 观察下限、20 rpm 反馈下限、
Id 质量门控、源时间/序号门控、独立保护、饱和估计连续性及饱和反馈保持/衰减。
补偿仍为 gain 0.25，独立 ±25 mA、总 Iq ±0.50 A、原斜率限制。

RAM 选择命令 `MOTOR TEST MECH DOB WARM SET 3` / `SET 5`；
`... WARM CFG` 回读。仅空闲、会话 READY 未使用、无 START/STOP 请求、
观测器未运行、DOB 反馈 OFF、SD/MOE/AOE/CCER 关闭且无 ADC/FOC 故障时接受。
不会写 Flash、重置板端限时或启动电机。非法值使观察器无效。

## 人工四轮协议

同镜像按 5 → 3 → 5 → 3τ，240 rpm，原 8 秒 rundown / 12 秒板端限时、
500 rpm 超速及所有原保护。每轮重新校准/预检、RAM 设置并回读，单次 START，
记录 Flash/RAM、整轮 60 ms 趋势和任务事件。正常结束、输出关闭、CPU 停住且镜像
闭合后才进行计划中下一轮；真正保护或证据失败停止整批，无自动重试。

若施加制动，每轮启动约 3 秒后在防护外短暂轻制动并立即解除。
制动器没有力矩/电气触发真值，手动负载不一致，结果只能比较内部预热和质量空窗，
不能据此证明真实扰动估计精度或控制性能改善。每组 n=2，保留全部结果和失败。
结束后人工关闭 12 V，再恢复 B 启动选择并停在 B 入口，不运行 B 应用。

## 四轮板测结果

实际顺序 5 → 3 → 5 → 3τ 全部完成，每轮 8000 次观察、单次 START。
均以原 8 秒 RUNDOWN_TIMEOUT 自然结束，CONTACT=0，未完成真实工件拧紧。
无独立保护、deadline miss 或 CCR late，FOC 最长 33.30 us。
原 B 启动选择已恢复，停在 B 入口，SD/MOE/PWM 关闭，没有运行 B 应用。

均值 ± 样本标准差，每组 n=2：

| 指标 | 5τ | 3τ |
|---|---:|---:|
| DOB 估计有效率 | 77.38 ± 0.95% | 82.02 ± 0.65% |
| 新鲜补偿更新有效率 | 76.35 ± 0.83% | 81.11 ± 0.40% |
| 全轮预热标记累计帧数 | 1281.5 ± 53.0 | 998.5 ± 16.3 |
| 分类质量重置→level 恢复 | 638.5 ± 38.9 ms | 391.5 ± 79.9 ms |
| 分类质量重置→trend 恢复 | 693.5 ± 41.7 ms | 455.5 ± 86.9 ms |
| 全轮速度峰值 | 278.70 ± 4.60 rpm | 288.29 ± 0.45 rpm |
| 全轮超出 240 rpm 的峰值 | 38.70 ± 4.60 rpm | 48.29 ± 0.45 rpm |
| 加速段速度 MAE | 12.88 ± 1.59 rpm | 14.42 ± 0.43 rpm |
| Iq 命令峰值 | 0.50 A | 0.50 A |
| Iq 饱和累计 | 272.5 ± 3.6 ms | 179.0 ± 48.1 ms |
| 补偿电流峰值 | 22.58 ± 3.43 mA | 24.90 ± 0.14 mA |

四轮分别为：

| 顺序 / τ | DOB 有效率 | 预热标记帧 | level / trend 恢复空窗 | 速度峰值 |
|---|---:|---:|---:|---:|
| 1 / 5 | 78.0500% | 1244 | 611.007 / 663.990 ms | 275.443 rpm |
| 2 / 3 | 82.4750% | 1010 | 335.007 / 394.054 ms | 288.603 rpm |
| 3 / 5 | 76.7125% | 1319 | 666.043 / 722.980 ms | 281.951 rpm |
| 4 / 3 | 81.5625% | 987 | 447.998 / 516.983 ms | 287.970 rpm |

每轮分类质量重置一次，源数据硬重置审计计数均为 0；二者计数范围不同。
第 1/3/4 轮的稀疏记录明确捕到 abs(speed)<10 rpm 的 ZERO_SPEED（状态 132），
随后为 WARMUP（8 或 136）。第 2 轮在记录中捕到 WARMUP，不能从 60 ms
稀疏数据确定其最低速度和准确低速持续时间。

3τ 平均估计有效率多 4.64 个百分点，趋势恢复空窗少约 238 ms，
但空窗同时包括低速退出、重新资格确认、有效预热及分类窗口/驻留。
不能把全部差异归因于理论上少的约 159 ms 预热。
预热标记帧不是累计有效 dt，也不是一次恢复时间。

第 4 轮 32 项事件环写入 36 项，覆盖最早 4 项；60 ms 整轮采样未发生覆盖，
分类器持续工作，唯一一次质量重置及两个恢复端点仍在事件环内，恢复区间完整。
分析器同时核对重置计数，禁止把丢失事件误解释为零次重置。

结论：3τ 达到了更早恢复估计有效性的目标，但本轮速度峰值、加速 MAE 更差，
不自动改为正式默认。手动制动力不匹配，且每组仅两次，无法建立因果或证明
3τ 扰动估计更准确/负载抑制更好。建议保留默认 5τ；若继续评估 3τ，先补同条件
空载对照与可重复制动/同步触发测试，单独检查更早补偿的过渡段。
