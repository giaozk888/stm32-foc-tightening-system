# DOB 短低速快速恢复板测候选

本次将已完成离线验证的200ms候选接入独立A构建，正式B保持原镜像。

## 改动范围

- `firmware_common/dob_short_low_recovery.h`：100字节短低速缓存/恢复状态。
- `firmware_common/mechanical_dob_monitor.c`：仅在 `FOC_DOB_SHORT_LOW_RECOVERY` 下插入前/后处理；在原seqlock的同一写事务内完成，并在更新统计/记录之前确定最终有效帧。
- `foc2_app_a/CMakeLists.txt`、`CMakePresets.json`：新增默认关闭的 `DobShortLowRecoveryCandidate`。
- `tools/dob_short_low_board.py`：固定BIN/ELF、单次运行、停止后读取真实恢复计数。
- `tests/test_dob_short_low_board.py`：5项板测准备回归。

该构建以100字节恢复状态替换上一轮68字节分段计时器，不同时启用两者；75ms趋势记录不变。
原有3τ、2Hz、输入质量门控、FOC、PI、前馈、Iq/电压限幅和独立保护均保留。

策略：低于10rpm最多保留100ms；同方向恢复、至少20rpm、未饱和且连续20ms安静真实样本后才投影状态，下一次合格更新才可有效。200ms是最多等待确认的期限，不是固定延迟。快速恢复失败继续并行的原冷启动路径，不额外再启动一次预热。

## 本轮人工测试与评价

单次240rpm普通START，DOB增益0.25、补偿最大25mA、总Iq±0.50A、超速500rpm、原8秒rundown和12秒板端限时。
预检通过才启动，操作人员在防护外于启动约3秒后短暂制动并立即解除；真实保护触发不重试。停止后保存Flash/RAM及整轮趋势，12V关闭后恢复B启动选择。

优先检查 `dob_low_recovery` 的fast/cold/held_epochs/confirm_epochs/low_max_us，以及原DOB有效率、趋势恢复、FOC耗时、deadline miss、CCR late和最终输出关断证据。
若未低于10rpm、低速超过100ms、恢复不安静或输入质量失效，可能完全不触发快速恢复；应报告实际条件和回退结果，不能把“运行完成”视为优化已生效。

离线实测噪声注入10次均未出现收益，因此本轮是候选可行性观察。没有制动器精确触发真值，趋势记录也不是1ms原始波形；单次结果不能证明实机闭环性能改善。

2秒后的60ms间隔趋势点速度范围207.7～262.3rpm，因此没有证据显示本次触发过短低速缓存，尚未检验快速恢复效果。
记录中的负载代理上升→趋势上升确认59.994ms、从峰值回落10mA代理→趋势下降确认118.023ms；二者均不是制动开关的绝对响应延迟。
FOC最大33.541us、deadline miss=0、CCR late=0。

运行3.483032s时建立低速缓存，3.484035s首次转回恢复状态，二者相差1003us；这只代表首次缓存片段，不代表整个制动低速持续时间。
60ms间隔趋势点在3.515023s记录到5.3rpm，在3.636950s记录到253.5rpm。
原始电流测量在个别趋势点可超过Iq命令限幅，不应把测量尖峰与IqRef限幅混为一谈；本次没有触发独立过流故障。

状态在冷启动恢复有效后会将reason清为NONE，因此停止时无法判定当时究竟由输入质量、再次低速/反向等哪一条件触发回退。
不能根据60ms稀疏趋势数据倒推出具体1ms帧的回退原因，也不能将446ms分类空窗全归于3τ预热。
结论：已实测到“进入缓存→回退”，但**仍未实测到快速恢复成功或预热缩短**。
两次制动力度不同且无同步真实负载真值，不能根据85.15%→82.30%宣称算法性能恶化。
若继续排查，应先添加不会在恢复后清掉的首次/最近回退原因和时间戳证据，不应先放宽质量门槛。
