# DOB增益调度优化：运行前固定方案

目标是减少上一版“gain从0等待分类＋250 ms淡入”的代价，不修改PI、观察器、质量门控、补偿电流斜率、独立限幅或正式参数。
本轮只在独立Simulink副本对照，速度调度保持OFF，固定240 rpm。旧实验和失败记录保留，正常A/B不改、不刷板。

## 因子对照

| 方案 | 轻载底gain | gain上升速度 | 其余行为 |
|---|---:|---:|---|
| 原调度adaptive（参考） | 0 | 1.0/s | 原30 ms证据、200 ms释放、300 ms最短加载 |
| fast | 0 | 5.0/s | 同上，只减少额外gain淡入 |
| floor | 0.10 | 1.0/s | 同上，只在可信分类下保留非零底gain |
| combined | 0.10 | 5.0/s | 同上，合并两个改动 |

固定0.25和DOB OFF作为另外两组参考。最大gain仍0.25，下降速度仍2.5/s。
gain上升加快不改变原0.25 A/s补偿电流斜率；总补偿仍min(25 mA,5%Iq limit)，总Iq仍±0.50 A。
底gain不是在数据无效时保持过期补偿：仍需原新鲜DOB／SAT128否决／≥20 rpm／可信分类条件；长缺口请求gain归零，补偿原5/20 ms时钟不延长。
CONTACT_CONFIRM和非SPEED阶段仍不开放新gain权限；原FSM、PI、S曲线、Ka／摩擦不变。

## 验证和可归因边界

新增3方案×14场景×每组10次=420轮，复用上一批OFF／固定／原调度420轮作为冻结参考，总840份对照记录。
参考CSV逐文件保存SHA256，旧DLL／源码核验；新DLL原profile1、fixed和OFF对旧DLL逐点比较相同。
每组使用同一原种子、外生输入和植物参数，实际消费值逐点核验。关闭Fast Restart，不用请求参数列代替实际模型参数。
覆盖无载、阶跃、斜坡、卸载、尖峰、持续Id异常、来源缺口、噪声、实测噪声回放、反转、早／晚接触、STOP和故障。
前5种子为开发集（历史回放来源1～3），61～65为留出集（回放来源4～5）；两个分组都报告，不按结果新增调参。
这两个分组沿用历史实验划分；此前已看过旧版的汇总结果，因此不能将本次61～65称为全新、未知的盲测。

验收沿用上次：加载MAE≤固定组105%+0.1 rpm，卸载峰值不得增大>1 rpm、恢复不得慢>50 ms，
无载平均绝对补偿不得比固定组增加>0.1 mA，接触完成数不降；原±0.50 A总限幅、25 mA补偿、来源／饱和／失效时钟等必须通过。
同时比较相对原调度的改善幅度、10次均值／标准差及成对改善／恶化次数。
通过该筛选仅代表软件候选可进一步交叉验证，不代表优于固定0.25或已验证真实电机。

当前A空间不足的问题不因仿真优化解决；不自动移植新状态或日志到固件。

## 代码／空间检查

新原生策略与完整控制器回归6项、独立审计反向注入3项通过；连同原增益13项和原速度策略28项，共50项回归通过。
固定gain／OFF／原profile1与冻结旧DLL在原生配对输入下逐点一致，含饱和场景。
对每个新profile验证快照恢复、总Iq／补偿限幅、SAT128不能刷新TRACK、原20 ms过期归零及STOP接管。
独立Cortex-M4对象编译通过，策略状态仍56 B，当前对象text=764 B；不包括整个固件链接影响。
当前A可用空间仍不足以直接叠加，本轮没有产生新的固件候选镜像。
