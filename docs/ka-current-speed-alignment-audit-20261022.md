# Iq/机械速度方向与辨识时间对齐：离线检测

本轮仅检查代码和已有五轮Flash/RAM/日志，不访问设备、不编译改写固件、不复位、不运行电机。
板端最后状态仍是原B975入口停住、输出关闭，用户此前确认12V关闭。

## 确认的方向链

- `main.c` ENCODER_DIRECTION=-1；机械速度、机械位置、检测速度、电角度都用同一方向。
- `AS5047P_InstantRpm` 使用 direction*delta/dt；电角度同样使用 direction*raw_delta*p。
- Park `Iq=-Ialpha*sin(theta)+Ibeta*cos(theta)`；逆Park使用相匹配旋转，没有单边反号。
- 速度误差ref-meas、正Kp；速度不足时正向Iq需求。
- 五轮评分窗口中，实测Iq窗口均值全部为正、实测机械速度正、净机械位移正。
  因此未发现“整体Iq/速度方向相反”的代码/运行证据；不等于代码能独立证明外部功率相物理映射。
- `encoder_speed_rpm` 声明处旧注释写 `+RAW=positive`，与当前-1配置不符。
  后续机械位置注释和真实函数运算均明确RAW下降为正；这是一条过时注释，未发现实际计算漏乘方向。

## 确认的测量链不匹配

速度链：

```text
encoder raw delta / encoder sample timestamp delta
  -> instantaneous rpm
  -> LPF alpha=dt/(.020+dt)
  -> filtered control rpm
  -> 约100ms窗口两端速度差分
  -> 用作 actual acceleration
```

Iq链：

```text
20kHz有效ADC/Clarke/Park -> foc_iq_A
  -> MotorControlTask约1kHz读取最近完整float值
  -> 100ms窗口梯形积分均值
```

前者有20ms一阶滤波，后者未经过同一滤波；在理想线性惯性模型成立时，
速度经过H滤波后，其导数对应H(alpha)，应该和H(Iq-friction)比较，不能直接当作无滤波加速度。
20ms是时间常数，不是所有频率下恰好固定延迟20ms。

速度dt使用encoder sample_us，观察窗口用任务调用时NowUs；样本年龄只有<=2ms的质量标志，
未保存逐点年龄。Iq值没有对应ADC序号/时间戳，current_valid_count仅证明计数在任务间推进，
不能证明每个Iq与该encoder采样严格同一时刻。由此不能从旧记录重建精确对齐。
这不是PWM pipeline或ISR内部控制时序被证明有错，只是辨识采集的时间语义不足。

## 旧数据的可识别性边界

每轮24个约100ms窗口，保存的是Iq均值和滤波速度端点。
窗口更新约10Hz，端点奈奎斯特约5Hz，而20ms LPF的截止约8Hz；
对可能存在的高速波动不能认为已充分抗混叠，不能把端点变化全当作低频真实惯性响应。
旧记录没有原始encoder逐点变化、1kHz Iq波形和电流年龄，无法精确纠正20ms延迟。

静止后固定摩擦命令约+.105 A。后600ms里减去一个常数只改变回归截距，
不改变Cov(accel,Iq)/Var(accel)斜率，不能仅靠换摩擦常数符号把负Ka变成物理可信值。

## 离线敏感性检测（不是重新标定）

工具：`tools/ka_alignment_audit.py`；报告：`tmp/ka-alignment-five-review.json`。
重新解码同镜像完整RAM/Flash，并与五轮已保存窗口逐字段一致后，才进行分析。

1. 各轮使用同一批后600ms窗口、同一配对数量，扫描Iq窗口相对加速度窗口的
   -200/-100/0/+100/+200ms名义移位。
   正移位定义为“较早的Iq窗口对应较晚的滤波速度加速度”。
   **没有任何一个移位使五轮均得到正斜率**，不能选择某轮最好的移位再宣称延迟已查明。
2. 假定每100ms窗口内电流恒定，近似给Iq-friction加20ms LPF，计算该假设下窗口均值。
   它不是原始1kHz电流的真实重放，只是检验敏感性：

|轮|原后段Ka|近似同LPF后Ka|近似同LPF后R²|
|---|---:|---:|---:|
|1|-.0000150715|+.0000305676|.3946|
|2|-.0000248936|-.0000338429|.2038|
|3|-.0000100027|-.0000167912|.0255|
|4|-.0000156150|-.0000191177|.0982|
|5|-.0000160703|-.0000132197|.1217|

只有1/5变正，且R²仍差。因此不能证明20ms滤波不一致就是负Ka的唯一原因，
更不能把该近似结果直接应用；没有自动选delay/Ka或改Iq符号。

## 结论与后续建议

已经确认测量链滤波和时间戳不完全匹配；尚未查明它对负斜率的定量贡献。
当前数据不足以验证真实惯量系数或否定全部物理相位问题。
下次应先在不改控制路径的独立诊断中保存更高时间分辨率的实测速度/原始位置、
Iq及其来源序号/采样时间，或按相同离线滤波/同时间边界聚合转矩与加速度，
再在已经运动的阶段采多段独立加减速，检查正反向一致性。
这些只是准备方向，本轮未实现固件变化、未申请或执行新板测。

4项离线检测测试通过：已知斜率/截距、阶跃LPF解析均值、真实五轮身份和同窗口延迟扫描、
禁止自动选参/设备入口。诊断A、正常A、既有B的BIN SHA256保持不变。
