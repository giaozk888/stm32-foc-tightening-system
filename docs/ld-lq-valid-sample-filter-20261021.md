# Ld/Lq 已保存样本的离线剔除与重算

本轮按“剔除异常观测、使用剩余样本”处理已有数据，没有刷板、运行电机或修改 MCU、PI、保护及正式 B。

## 输入与追溯

- 原批次：`tmp/motor-ident-voltage-batch-1792561436183568200.json`
- 严格报告：`tmp/motor-ident-voltage-valid-samples-strict.json`
- 静态时序假设下的诊断报告：`tmp/motor-ident-voltage-valid-samples.json`
- 工具：`tools/motor_ident_valid_sample_report.py`
- 回归：`tests/test_motor_ident_valid_samples.py`

工具核对同次实验的 RAM、Flash、ELF/BIN 哈希，以及二进制帧与 JSON 解码一致性。Rs 仍只作为用户指定的 0.78 Ω 假设，没有重新确认其物理准确性。

## 样本准入

仅对原始完成、无保护故障的锁轴采集进行离线筛选。命令稳定、原始序号连续的局部窗口中，使用 median-of-5/MAD 识别同时偏离两侧邻居的孤立电流观测。偏差门槛为 `max(15 mA, 3 × 1.4826 × MAD)`；避开电压阶跃起点，避免把正常阶跃响应当作尖峰删除。

这是新增的离线观测筛选规则，不是修改运行时 current discriminator 或硬件故障判据。它不能证明每个被标记的点都是硬件毛刺，也不保证把所有异常都识别出来。

- 不修改、不插值、不替换原电流。
- 不压缩时间，不把跨两拍的间隔当成一拍。
- 被剔除电流对应的原电压命令与时间历史仍保留。
- 只有全部中间电压/时间/command-source 历史完整，才可用两端实际电流观测建立跨点 RL 模型区间。
- 真正缺少电压历史的区间排除，其他完整区间继续使用。
- 至少保留 70% 且不少于 16 个电流观测，以及不少于 16 个模型区间；不无限吞异常。
- 原保护故障段不能通过过滤变成合格实验。
