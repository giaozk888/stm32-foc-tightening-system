# DOB 短低速快速恢复：离线候选与实际结果

日期：2026-10-24。范围：Simulink 中的观测器独立对照；不刷板、不启动电机。
本轮未改 MCU A/B 源码、默认参数、FOC、电流反馈和安全保护。

## 实现

当前 MCU 在速度低于 10 rpm 时清空 DOB 观测状态，恢复速度后重新累计 3τ（约239ms）有效更新。
新增软件专用包装器保留最近有效的状态，同时让原始冷启动观测器继续运行：

1. 进入低速前必须已有有效估计及合格输入。低速状态最多保留100ms；低速期间不发布有效估计，不增加预热时间信用。
2. 同方向恢复后，输入仍须通过原来的时间、序号、Id 和尖峰检查。
3. 测速至少20rpm、未饱和，且有连续20ms真实样本满足速度范围≤0.5rad/s、归一化驱动电流范围≤10mA，才允许状态投影。
4. 投影扰动为该窗口平均驱动电流减去端点速度变化对应的惯性电流。下一次真实合格更新后才允许有效；并非直接复用低速前的旧负载估计。
5. 原冷启动路径一直并行推进。快速确认失败时不重新启动该路径，不额外叠加一遍预热。
6. 长低速、反向、尖峰、输入失效、持续Id异常或故障放弃缓存；恢复期饱和不能完成快速确认。实际保护路径不经过本包装器。

缓存尝试的恢复期限分别测试150ms和200ms。它是最大确认期限，不是固定等待时间；期限内未达条件就继续原冷启动。
150ms方案没有实际收益，原结果完整保留；200ms方案只在合格场景中产生收益。
原补偿5ms保持/20ms衰减、增益0.25、补偿限幅25mA和总电流限幅均未改变。

## 对照方法

- 14种场景，每种10个随机种子；每组相同输入同时比较原算法、150ms候选、200ms候选。最终140次Simulink运行、420份估计器结果。
- 场景覆盖无低速、20/60/90ms低速、150ms长低速、反转、单点尖峰、源缺失、持续Id异常、负载变化、噪声、恢复期饱和、实测噪声注入和故障。
- 复用现有 C 观测器、输入准入与补偿限幅模块。源文件SHA256、输入SHA256和实际Simulink消费的输入均核验。
- 速度为规定轨迹，电流根据机械模型和独立负载生成；真实负载只进入日志，不能进入估计器。补偿仅作为影子输出，不驱动机械模型。
- 实测噪声来自此前五轮记录的Id、Iq残差和速度高频分量；它是噪声注入假设，不是实测外部负载真值。
- 种子1～5使用实测记录1～3，种子61～65使用记录4～5。200ms是探索性候选，不能把这些结果称为独立盲测。

## 结果

恢复时间从低速平台之后**首次测得绝对转速达到10rpm**开始，至首次DOB有效结束。
表中均为10次均值±样本标准差，单位ms；并不是趋势分类标签的完整空窗。

| 场景 | 原算法 | 200ms候选 | 快速恢复次数 |
|---|---:|---:|---:|
| 20ms低速平台 | 239.00±0.00 | 164.30±9.10 | 10/10 |
| 60ms低速平台 | 239.00±0.00 | 163.50±8.53 | 10/10 |
| 90ms低速平台 | 239.00±0.00 | 164.30±6.41 | 10/10 |
| 恢复后负载变化 | 239.00±0.00 | 163.70±8.50 | 10/10 |
| 增大随机噪声 | 239.00±0.00 | 173.20±25.92 | 9/10 |
| 实测噪声注入 | 254.50±3.69 | 254.50±3.69 | **0/10** |
| 长低速150ms | 239.00±0.00 | 239.00±0.00 | 0/10 |
| 单点尖峰/源缺失/恢复饱和 | 各239.00±0.00 | 各239.00±0.00 | 各0/10 |

60ms平台场景平均减少75.50ms。恢复后500ms窗口内，仅有效点的估计RMSE从5.58mA降至2.40mA；有效覆盖率约51.62%→66.72%。
这两个数需要一起看，不能只比较剔除无效点之后的误差。
实测噪声场景中7次尝试回退、3次未满足进入缓存条件，最终没有收益；RMSE仍约5.09mA。
150ms方案所有场景均没有快速恢复收益，不能因为安全/精度检查通过就称其优化成功。

## 回归及边界

- 7项原生回归通过：无低速输出一致、真实确认时间、长缺口回退、饱和回退、尖峰/缺源/反转/NaN/故障隔离、状态快照重放、200ms饱和边界。
- 140组结果审计通过：NaN/Inf、输入一致性、低速/故障不发布有效估计、25mA补偿限幅、有效反馈斜率、尖峰不更新Id LPF、危险场景不快速恢复、逐段恢复不慢于基线等。
- 验收上限：恢复后500ms有效点RMSE≤12mA、平均偏差绝对值≤8mA、影子误补偿峰值相比基线增加≤5mA。上述离线数据通过；不代表所有电机工况通过。
- 第二批的原算法及150ms候选与第一批逐点结果完全一致，没有用修改基线掩盖收益。
- 原始Reset函数调用计数可能仍然很高，因为原冷启动在并行处理。收益指标是减少重新累计完整预热的次数/时间，不能用Reset调用次数冒充它。

## 当前结论和下一步

条件式快速恢复已在软件中实现；干净短低速可减少约75ms估计恢复时间。
**实测噪声注入下尚无收益，因此本轮不直接接入MCU默认行为。** 下一步先分析真实噪声导致缓存失格和确认窗口中断的原因，并做机械参数偏差、闭环反馈验证，再决定是否准备板测候选。
当前模型与观测器共用名义机械参数，尚未覆盖参数不确定性。
本轮未模拟全部FOC/速度环闭环，也未重测75ms分类器，不能宣称速度峰值改善或原约480ms分类空窗已缩短到164ms。
