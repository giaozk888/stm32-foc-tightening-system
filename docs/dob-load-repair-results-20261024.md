# DOB负载分类与短来源缺口：修复结果

本次仅修复Simulink/主机副本。13场景每组10个相同种子，旧/新各10次，共130对、260次仿真。未修改MCU固件、正式B、PI/前馈参数、独立保护或真实安全限幅；未烧录或启动电机。

## 两处修复

1. 等级和趋势分离：`load_state`仅表示UNKNOWN/LIGHT/MEDIUM/HIGH；新增独立趋势状态、滤波值、有效位和确认计时。重载上升/重载下降可同时表达，趋势不再替换等级。原10/25mA等级阈值、5mA迟滞、30ms确认不变；趋势增加100ms滤波、80ms确认与退出迟滞。
2. 来源缺口适配：仅在专用主机宏下处理此前已有效的观察器。缺失和两个真实恢复确认点合计不超过5ms才保留内部记忆；这些帧均无效、不更新LPF、不积分/预热。恢复需来源时间/序号推进、原200mA一致性、同向且速度变化≤0.5rad/s。超时或不一致，旧估计作废并重新预热；持续来源缺口仅执行一次Reset。编码器/时序/饱和/持续Id等原异常路径没有放宽。

0.5rad/s是此仿真适配器的质量边界，不是硬件保护参数。“保留记忆”不等于给无效帧有效信用，更不允许绕过真实CURRENT_INVALID。

## 代价和仍需保留的限制

- 典型合成阶跃/卸载中，趋势上升检测由53.5±1.1ms变为133.9±0.7ms，下降检测由53.4±0.8ms变为133.5±0.5ms。抗抖动以更多确认时间为代价。
- 等级不再被趋势覆盖，典型HIGH确认由367.6±5.8ms变为187.8±0.8ms；这不是DOB估计本身变快，因为无来源缺口时原33项输出完全相同。
- 卸载后等级可能仍暂时为HIGH、趋势已为FALLING。合成卸载评估中，真实轻载期间HIGH占比从1.78%变为5.31%；两种实测假设分别从1.70%/0.46%变为4.66%/4.32%。这项没有隐藏，后续不能只看等级就持续增加补偿。
- 电流脉冲假设中独立趋势仍平均切换10.3次，且2/10试次在真实负载事件前就有RISING。此类提前激活保留为错误/不确定证据，不算0ms完美检测；对应延迟记N/A。
- 真实电流尖峰到底来自测量还是实际转矩脉动没有独立真值，两个假设都保留。上述软件检查通过不表示负载分级已完成物理标定，更不表示真实拧紧性能已验证。

## 审计与回归

- 主机GCC DLL、独立MSVC MEX和两个Simulink模型实际构建运行完成。新旧DLL使用不同MEX加载实例，防止缓存误用同一版本。
- 910130个对应采样点独立审计通过：控制、机械真值及外部输入完全一致；旧基线逐点匹配上轮历史原始日志，旧分类器亦逐点匹配。
- 无来源缺口的场景中，原33项控制/观察器输出完全相同。缺失/恢复确认帧无LPF、预热或有效信用，单+700mA尖峰仍不污染滤波器；NaN/Inf、原总Iq限幅与软件守卫检查通过。
- 九项预先声明的软件准入检查通过：两个实测假设的等级切换至少减半；短缺口无Reset且≤8ms恢复；长缺口失效并只Reset一次；无载/单尖峰无HIGH误报；正向/卸载/反向的HIGH确认在800ms内。
- 回归包括等级/趋势分离、缺口1/2/3/4ms边界、长缺口、坏恢复点、速度突变、时间/饱和不进入保持、uint32时间戳回绕、缺口中快照完整性及审计器故意注错。

仍只运行只读观察，不启用速度/Iq限幅/补偿增益/FSM自适应。若将来移植到候选A，需要先明确实际来源无效原因的分类，并验证MCU状态发布、RAM/IRQ预算和实机行为；当前没有完成该移植。
