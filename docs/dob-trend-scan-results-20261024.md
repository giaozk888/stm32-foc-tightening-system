# 趋势时间参数四格对照：每场景每组10次

结论：本批软件对照保留100ms趋势滤波常数、80ms有效确认时间。三个更快候选均增加了至少一种假设下的额外激活/漏检或降低了可用时间，未通过预先声明的条件。没有自动应用参数，也未修改固件或运行硬件。

## 实验范围

13类场景，各10个固定种子。每条模型轨迹上同时运行四套独立DWork的只读分类器，合计130次Simulink运行、520份参数评估，不是520次独立模型/电机试验。四路控制/DOB输入完全相同。

仅改变趋势EMA时间常数和有效确认时间；100ms统计窗口、10/25mA等级阈值、5mA迟滞、等级30ms确认、DOB带宽、所有PI/前馈/质量/限幅和短缺口策略保持不变。默认配置仍为100/80ms，DOB反馈在本软件实验中OFF，未接自适应控制。

## 实际结果

|趋势滤波/确认 ms|合成阶跃上升延迟，均值±样本SD|全场景匹配事件平均延迟|经验P95|最慢匹配|额外激活总数|漏检总数|
|---|---:|---:|---:|---:|---:|---:|
|100/80，原基线|133.9±0.74ms|145.89ms|275ms|309ms|32|2|
|100/40|93.9±0.74ms|105.11ms|232ms|269ms|120|1|
|50/80|124.2±0.79ms|140.03ms|253ms|784ms|75|7|
|50/40|84.2±0.79ms|93.29ms|208ms|228ms|182|2|

额外激活/漏检是每参数在130条轨迹中的合计，不是单次7秒的数量。延迟只对成功匹配事件计算，漏检不填0；必须联合读取。P95是此有限样本的经验分位数。

典型合成卸载的下降检测分别为133.5±0.53、93.5±0.53、124.0±0.67、84.0±0.67ms；这些简单场景四组都没有额外激活或漏检。但实测短窗回放不能据此类推。

### 实测短窗的两种假设

|参数 ms|测量假设趋势切换/7s|测量假设额外激活/漏检，10次合计|电流脉冲假设趋势切换/7s|电流脉冲假设额外激活/漏检，10次合计|
|---|---:|---:|---:|---:|
|100/80|5.0±0.0|0 / 0|10.3±2.00|32 / 2|
|100/40|5.0±0.0|0 / 0|21.2±4.29|120 / 1|
|50/80|5.0±0.0|1 / 1|13.5±4.01|74 / 6|
|50/40|6.6±2.07|10 / 1|26.3±3.95|171 / 1|

50/40在加强合成噪声场景中还多出1次额外激活，所以全场景总数为182。100/40在纯测量假设下明显更快且未增加这批误报，但在真实电流脉冲假设下不稳；目前不能确定实测尖峰的真实物理成因，不能只取有利假设。

## 选择及未通过项

选择规则在正式运行前固定：前5个种子训练选择，后5个留出验证；任一场景额外激活/漏检不增加、趋势有效时间不减少，两种实测假设的趋势切换均值不超过原基线1.25倍。合格者才按匹配事件平均延迟排序。

- 100/40：训练及留出均因电流脉冲假设的额外激活和切换增加而未通过。
- 50/80：出现额外激活、漏检；持续Id恢复场景趋势可用时间也略少，未通过。
- 50/40：额外激活明显增加，部分场景漏检或切换超标，未通过。
- 100/80：作为原基线保留，训练/留出一致。本批没有更快且同时满足既定质量条件的新参数；不表示基线已经消除了所有误激活。

## HIGH滞留与控制边界

四路原16项负载等级/特征/质量输出逐帧相同，所以本轮没有改善HIGH滞留。典型合成卸载后HIGH退出约159.2ms，四组相同。缩短趋势确认只改变FALLING标签，不会自动改等级，更不会自动改变speed_ref、Iq_limit或FSM。

趋势检测时刻统一从模拟器真实事件开始（3.0s施加载荷、4.6s卸载），斜坡同样从开始变化计时；因此全场景平均不是此前典型阶跃的134ms。一个真事件最多匹配一次，匹配窗口0～800ms；提前、重复或事件外进入算额外事件，无法匹配的真事件算漏检。质量缺口后同一标签的恢复不重复当新进入。

这些误激活是相对于合成外部载荷真值的操作定义，不证明实际尖峰的物理来源。当前只能说明简单缩短时间会引入明显取舍；下一轮如继续优化，应另行验证“快速候选＋稳定确认”或多信号交叉证据，不能把最快的50/40直接用于控制。
