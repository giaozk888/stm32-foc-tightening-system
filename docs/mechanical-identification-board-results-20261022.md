## 离线拟合

使用实测机械角速度（rad/s）和实测 Iq，而不是 accel_ref 或 IqRef：

`Iq_lp20 = (J/Kt)*actual_acceleration + (B/Kt)*omega + (Tc/Kt)*sign(omega) + bias`

摩擦补偿命令没有再次从实测 Iq 扣除；摩擦项在同一个回归中估计。没有按残差挑样本、翻转惯量符号或搜索时间偏移。

547 个完整窗中保留 483 个；64 个因预先定义的静止/起转、方向变化或 |Id| 质量条件排除。拒绝原因可重叠：REST_OR_BREAKAWAY 58，DIRECTION_CHANGE 9，ID_NOT_NEAR_ZERO 6。完整数据仍全部保留。

主拟合缩放后条件数 30.6514；六段逐一留出验证全部通过。**但 J/Kt 随窗口从 64 ms 改为 128 ms 增加 84.32%，超过既定 30% 一致性要求，最终 normalized_qualified=false，唯一最终失败项 WINDOW_SENSITIVE。**

高 R² 不能替代惯量项的稳定性：本次摩擦/速度项比惯量项稳定，但未据此自动选定任何最终模型。不能单凭该结果断定窗口敏感性来自某一个具体环节；后续仅可先对保存数据审查滤波、积分窗口边界与加速激励，不必立刻重新上板。

没有独立校准的 Kt，本轮只提供比值候选；绝对 J、B、Tc 保持 null，Kt 未被独立辨识。人工选择的有效 BEMF 前馈系数不是物理磁链标定值，未用于假定 Kt。
