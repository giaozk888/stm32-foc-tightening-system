# DOB 恢复空窗分段计时候选

本轮仅实现观察记录与离线分析，不改变 3τ + 75ms 设置、不修改控制或保护参数，
不刷板、不复位、不启动电机。原 B 和当前板上镜像未在本轮改动。

## 已确认的代码事实

- `DobAdmit_Qualify` 的50ms同向资格只在会话首次建立时执行。
  一旦armed=1，该函数直接返回；低速恢复不会重新等待50ms。
- 分类器超过20ms没有合格数据后清空分类状态。1ms调用下，重置通常在
  最后好点之后20ms、首个坏点之后19ms发生，二者不能混为同一起点。
- 等级确认30ms与趋势确认80ms同时推进；不能直接把两者相加。
- 3τ是有效更新时间门槛，不等于所有恢复空窗。跳点/恢复帧、低速、重新积累
  分类证据等可能延长实际墙钟时间。

## 新增记录

新 preset：`DobRecoveryBreakdownCandidate`，继承已板测的
`DobWindow75Warmup3Candidate`，仅增加默认关闭的 `FOC_DOB_RECOVERY_TIMING`。
`MOTOR TEST MECH DOB RECOVERY CFG` 只读报告 ABI；记录以停止后的匹配ELF/RAM解析。

对每个长恢复片段记录：

| 字段 | 含义 |
|---|---|
| first_invalid_us | 首次观察到趋势不可用的时刻 |
| start_us / end_us | 实际分类重置→趋势恢复；初次启动则从首次观察开始 |
| low_us | 测得速度低于原10rpm观察下限/原低速状态的墙钟占用 |
| qualify_us | 真正未armed的首次同向资格等待；普通低速恢复为0 |
| warm_us | DOB未有效、处于WARMUP且未被更高优先级质量原因阻断的墙钟占用 |
| quality_us | 源时间/序号、Id质量、跳点/恢复等输入等待 |
| window_us | 45点/45ms跨度或覆盖不足的分类窗口等待 |
| level_us | 窗口已有更新，但负载等级尚未确认的占用 |
| trend_us | 等级已确认，但趋势尚未确认的剩余占用 |
| other_us | 停机/故障等不能归入上述阶段的占用 |
| warm_credit_us | 此片段观察到的内部预热elapsed增量；不再加到墙钟时间里 |
| flags_reason | 见过的状态位OR，以及完成/中断/时钟不确定/初次/实际重置等标记 |

八项墙钟分段互斥，解析器强制检查其和等于 `end_us-start_us`。
输入不足时不会插值或补造时间；超过2ms的观察缺口、重复时间戳标记为不确定，
这类记录不能宣称精确分段。实际时刻以约1ms任务采样为分辨率，边界约有一拍误差。
同一帧有多个等待条件时按代码中的源错误→低速→资格→质量→预热→分类顺序
归类，状态位保留多原因信息；它是观测路径占用，不是因果贡献的精确分离。

初始预热及≥20ms的片段保存最新3条。短暂缺口只累计次数，不清空控制/观测器，
也不会冲掉已保存的长片段。另有1条正在进行的记录；环覆盖显式计数。
若运行中止，记录标记中断而不是伪装成恢复成功。

## 内存与控制路径

原75点窗口的实体数组仍有100项。借用未使用的最后25项value和stamp，合计200B，
存放3×48B已完成记录和1×48B待完成记录；通过memcpy传输，不做结构体别名强转。
分类器只读取前75项，原清质量状态不触碰这些借用区域。
增加68B全局计数头（链接RAM增量含对齐为72B），不改变原分类/记录ABI，不增加环。
原记录器、原始电流反馈、PI、S曲线、前馈、摩擦补偿、DOB参数、饱和处理、
CUR_CONFIRM、CURRENT_INVALID、独立保护与IRQ优先级均不改。

唯一调用点位于原控制ACK之后、DOB及分类器更新之后，并检查记录器指针非空。
诊断只读取控制/模型状态，写专用计数头和未使用的分类缓冲尾部，不能开启输出、
修改参考、清故障、改变观测器或重启预热。正式默认profile与B均不启用此选项。
