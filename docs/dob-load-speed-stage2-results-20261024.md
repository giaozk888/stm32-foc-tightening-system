# RUNDOWN按负载平滑降速：实现与每组10次结果

**已完成独立Simulink候选、280次仿真和结果审计；当前120rpm策略未通过全部验收，不接入固件默认行为。**
本轮未烧录、未启动电机，未改生产A/B源码、参数或安全阈值。以下均为软件模型结果，不是实机性能证据。

## 具体加法

在原FSM的 `ControlIntent.speed_target_rpm` 与原S曲线之间增加纯软件 `LoadSpeedScheduler`。
原FSM给base target，调度器给selected target，原S曲线继续生成speed_ref/accel_ref；三个值分别记录，禁止覆盖原配方。

1. 仅RUNDOWN可以选择降速。高负载，或持续上升且均值≥10mA，累计30ms有效证据后选择120rpm；原目标为240rpm。
2. 负载回到LIGHT且不在上升，累计200ms有效证据，并且已低速至少300ms后，恢复原目标。
3. 短缺口保持当前决定，不把无效点当成零负载；200ms无有效分类后取消降速权限，回到原目标。两种目标切换都经过原S曲线，不Reset轨迹。
4. Iq上限仍±0.50A，DOB gain仍0.25，补偿上限25mA；PI、Ka、摩擦、3τ/2Hz和75ms分类不改。CONTACT仍使用原实际速度/电流/250ms驻留规则，不屏蔽接触。

完整方案及边界见 `dob-load-speed-stage2-design-20261024.md`。

## 完成的验证

14类场景，每类OFF/ON各10次：共280次，每次10秒，1ms控制和50us机械更新。
覆盖空载、负载阶跃/斜坡/卸载、尖峰、持续Id异常、来源缺口、噪声、历史噪声回放、反转、早/晚接触、STOP和故障。
固定种子，配对外生输入和模型参数逐点一致。机械参数随机偏差包含惯量/粘性各±10%、摩擦±5%；接触位置±10%。

原生策略、完整控制/FSM适配、快照恢复、真值隔离及报告逻辑共**11项回归通过**。
全部仿真日志NaN/Inf、总电流限幅、仅RUNDOWN调度、目标幅值边界、固定Iq上限和DOB gain、原CONTACT先后关系、STOP/故障零输出检查通过。
无载和单尖峰各10次均未触发降速；全部测试没有“工件尚未接触而调度误CONTACT”。

## 主要取舍

下表为10次均值±样本标准差，OFF/ON除降速调度外采用相同配置：

| 模型与指标 | OFF | ON |
|---|---:|---:|
| 较早接触：接触前速度 | 239.982±0.088rpm | 119.986±0.054rpm |
| 较早接触：完成时间 | 5.288±0.113s | 5.932±0.225s |
| 较早接触：电流饱和时间 | 244±0ms | 223±0ms |
| 较早接触：完成数 | 10/10 | 10/10 |
| 较晚接触：完成数 | 10/10 | **5/10** |
| 较晚接触：触达工件数 | 10/10 | 8/10 |
| 较晚接触：完成接触确认数 | 10/10 | **5/10** |
| 卸载后回到240rpm±5并保持100ms | 242.7±2.54ms | **1182.4±1.65ms** |

较早接触模型接触前速度约减半，完成时间平均增加0.644s，饱和时间减少21ms。
这是理想挡块下的接触入口速度，不能直接当成实际冲击扭矩或拧紧质量改善。

较晚接触模型中，有2次未触达工件，另3次虽触达但来不及完成原250ms接触确认；均受原8秒rundown限时约束。
ON完成的5次平均耗时9.624s，仅为成功子集，不能把它当成10次总体完成时间。没有延长原限时掩盖失败。

卸载恢复更慢主要来自降速决定释放及S曲线重新加速，不能解释为DOB本身估计延迟增加。
对保持高负载且没有真实接触的场景，120rpm会降低行进速度/行程；降低目标后的跟踪误差不作为单独优越性结论。

## 未通过项

1. 较晚接触5/10新增未完成接触确认，导致未完成原FSM。严格验收失败。
2. 持续Id异常与来源缺口各10次，在失效回退→再次降速的重定向处，原单精度S曲线的采样jerk分别达到1000.209868和1000.236547rpm/s²，略高于运行前固定的1000.2数值验收界。
   相对名义1000约为0.021%/0.024%偏差。未修改S曲线、PI或验收门槛来隐藏它；这些20项严格检查保留失败。

独立审计共30个失败条目，涉及25个不同ON运行：20个jerk边界运行，加5个晚接触运行（这5个分别记接触确认未完成和新增过程失败，不能重复算成10轮失败）。
所以不能报告“全部回归/场景通过”。11项单元回归通过与场景验收失败是两种不同结论。

## 下一步建议

当前先保持为软件候选，固定120rpm不直接上板。
下一版优先加入RUNDOWN剩余时间预算和降速持续时间管理，避免未知接触位置下长期低速；在相同10组条件复测，优先消除晚接触新增超时，而不是延长保护限时。
来源失效时恢复240rpm又因高负载再次降速，也应评估是否需要更明确的恢复许可/驻留，以减少往复重定向。
S曲线数值边界单独审查，不改本轮PI/jerk参数；保留此次严格失败作为回归基线。
