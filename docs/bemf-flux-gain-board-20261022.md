# ψf 五档各三次：240 rpm 空载对照

## 结论

15 轮全部采集完成，每档三次，固定 Ka=0.000046875 A/(rpm/s)（原 Ka 的 0.25 倍）。本轮 0.5 倍 ψf 的加速平均绝对误差最低，1.0 倍的匀速误差最低且加速误差波动更小。没有出现减小倍率就持续改善的单调规律，不能凭此确认原物理磁链明显偏大。

如果优先加速跟踪，可把 **0.5 倍 ψf = 0.00034866 Wb** 列为后续候选；并未自动把这一候选写入正常控制或正式 B。三次样本较少，组内波动与组间差异同量级，不宣称统计显著或磁链重新标定成功。

用户确认 12 V 关闭后，已恢复原 B 启动选择，GEN=1007、confirmed B、pending=0；B 应用未运行，输出关闭、MCU halted。

## 保护、采集和时序

- 每轮 START=1；15 轮全都完成 8000 点 AFF/FRIC 聚合，完整 Flash/RAM 与各自哈希已保存。倍率命令回读、START 前状态回读、最终 RAM 倍率均一致。
- 每轮均为空载自然 `RUNDOWN_TIMEOUT`、CONTACT=0、FLT=0；原 8 秒流程超时保留，不是独立硬保护故障，更不是真实拧紧 OK。
- CUR_CONFIRM enter/clear/fault 合计 **1958/1958/0**；所有轮次 encoder first fault、timeout、DMA error、schedule miss、control stale 均为 0。
- Iq 饱和累计各轮均 0 ms；FOC wall 最大 **33.147 us**；deadline miss=0；actual CCR commit 共 **4501629**，late=0；actual margin 最小 **12.347 us**。
- 218 个运行中 coherent BEMF 电压帧检查通过：`Vq_ff = omega_e * psi_base * gain / 100`。这些帧中电压饱和=0；这是稀疏查询，不是全速率电压峰值/饱和持续时间证明。
- UART 共丢弃 2496 字节，不能称为完整串口流；每轮板端聚合与独立 RAM 快照保留，主要误差指标不从有缺帧的串口 STATUS 重建。
- measured Iq 峰值仍含瞬时波动（与 Iq 命令峰值不是同一概念），未据此擅改采样或保护。

## 最终安全状态

恢复 receipt PASS，原 B 应用大小 **227964 B**、CRC **627317606** 不变；A/B 应用、boot 与私有配置核验未改，只有预期启动元数据推进。confirmed B、pending=0、GEN=1007，VTOR=0x08040000。最终 SD=0、BDTR=0、CCER=0、CPU halted、恢复期间 motor_commands=0，未运行 B 应用。
