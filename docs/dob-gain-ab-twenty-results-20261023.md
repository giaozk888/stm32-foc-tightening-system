# DOB增益0.25 / 0.5实际空载各十轮结果

结论：这次240rpm空载实测不支持从0.25改成0.5。0.5补偿电流约翻倍，但主指标加速/匀速误差以及超调的均值均略差。差异伴随较大的逐轮波动，试验未随机化，不能将均值差当作普遍或确定的因果关系；继续保留正式0.25，不自动采用0.5。

0.5的低速均值及固定短窗均值略好，但主指标不随之改善，不能以短窗挑选替代完整加速/匀速统计。10对中0.5加速MAE四对下降、六对上升；匀速MAE三对下降、七对上升；超调五对下降、五对上升。全部Iq饱和时间为0，不能用触顶解释这次差别。
