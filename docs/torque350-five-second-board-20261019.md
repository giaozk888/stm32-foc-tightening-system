编码器在前约 0.2 秒报告约 +3.19°；之后保存的任务快照位置均在 +3.14209° 至 +3.27393° 之间，没有持续增加。
用户现场肉眼未见实际转动，所以上述仅为编码器报告的小位移，不能当成独立证实的实轴偏转；无持续旋转证据。
因此测试流程和停机检查 PASS，**持续转动不通过**。

4999 点原始编码器累计绝对变化换算为约 217.13°，但包含约 1 kHz 分辨率下的往返计数和编码器抖动；不能称为电机实际转过 217°。
软件 instant rpm 也包含这些量化/抖动，不应凭瞬时峰值证明连续旋转。
原 SPEED PI 的 `speed_diag_*` 在 IQ 模式未累计，本次它们的零值不能作为实测速度 extrema。

Iq/Id/Vdq 统计来自 25 帧抽样，包含启动最初约 1 ms 的电流爬升；不代表所有 20 kHz 样本的峰值/均值。
这些是软件电流反馈，没有独立电流、扭矩或转速测量，不能仅由 Iq 跟踪断言摩擦或电角度就是根因。

零点 4000 valid / 45 reject / 4045 total，最大连续 reject=1；zero U/V=1560/1563。
完整窗口 bad_ref、bad_gates、bad_encoder 均为 0；所有保存的驱动帧均为 IQ 模式、门极已使能、IqRef=0.35 A。
原 PI、采样判据、保护阈值、相序、电角零点和 PWM pipeline 未修改。

测试后 STOP/ANALOG SAFE、SWD 输出关闭并停住 MCU；用户确认关闭 12 V 后，仅恢复原 B 启动选择，未再运行电机。
恢复收据：`tmp/torque350-restore-1792400493770134200.json`。
应用、bootloader、私有参数均保留；B 应用在入口前停住，SD/MOE/AOE/CCER 关闭。

结论：固定 +0.35 A 持续 5 秒并没有消除停滞，不能把之前所有问题简单归结为“小电流给定或速度环测试时间短”。本轮不据此自动更换相序、电角零点或继续加流。
