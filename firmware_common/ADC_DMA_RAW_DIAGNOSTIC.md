# IU/IV 定时器触发＋规则 ADC＋DMA 原码诊断

> 2026-10-10 新增独立三路诊断开关，实际采 PC3 / IW。默认双路模式、历史固定镜像与工具不变；三路模式使用不同命令与数据格式，见 [三路原码诊断](ADC_THREE_PHASE_DIAGNOSTIC_20261010.md)。尚未完成三路上板验收。

本功能用于排查电流检测输入和 ADC 采集链路，不是电机运行固件，也不是零点校准通过证明。

## 采集路径

`PA0/IU → ADC1 IN1 → DMA1 CH3 → U[4096]`

`PA1/IV → ADC2 IN2 → DMA1 CH4 → V[4096]`

两个 ADC 保持独立模式、SYSCLK 异步 /4（42.5 MHz）、12 位和 12.5 周期采样时间。规则转换均选择 TIM1 TRGO2 上升沿，由内部 CH4 OC4REF 触发；TIM1 PSC=0、ARR=4249、CCR4=3500，中心对齐。名义采样率为 20 kHz，4096 对约 204.8 ms；没有每个样本的硬件时间戳，因此导出文件的时间列只是名义时间。

只有 `ZERO_RETEST_BOOT=ON` 时才能启用 `ADC_DMA_RAW_DIAGNOSTIC=ON`，默认关闭。没有修改正常 FOC 注入采样控制算法、滤波器、零点门槛或电流限幅。

## 为什么使用有限长度 NORMAL DMA

本次目标是保留完整原码便于对照，而不是连续后台日志。两块静态数组共 16 KB，不经过堆分配，也没有循环 DMA 覆盖。

先停止定时器和两个注入转换，再保存原规则采样设置，配置两路规则 ADC 和 DMA。两路都完成预备后，才启动内部定时器。关闭 DMA 半满中断；正常完成预期各有一次 DMA 完成回调。第二路完成时立刻停止触发，后台再停止 ADC/DMA 并恢复原配置及注入转换的预备状态。

只有两路均完成 4096 个转换、无 ADC/DMA 错误、输出仍锁定且恢复成功，才公布 READY。CPU 读取原码只在 READY 后发生，不会读取正在写入的数组。DMA 先后完成顺序不影响导出；相同触发源和计数检查不能替代外部同步时序测量。

SD 始终低、MOE/AOE=0、CCER=0，FOC 不执行。这里启动 TIM1 只产生内部触发，不开放 PWM 输出引脚。采样期间暂停 VBUS/TEMP 背景规则转换，拒绝升级、参数和其他采样命令，避免重配 ADC。

## 命令

仅接受本地 UART，每条仍需要原有请求编号，例如 `81001 ADC DMA STATUS`。

| 命令 | 用途 |
|---|---|
| `ADC DMA STATUS` | 输出锁、状态、错误、两路数量、中断数、范围和 CRC |
| `ADC DMA SAMPLE` | 一次有限采集；失败也不自动重试，同一启动最多一次 |
| `ADC DMA READ 0` | 导出第 0～15 对，每对四位 U＋四位 V 十六进制 |
| `ADC DMA READ 16` | 导出下一块；索引必须是 16 的倍数且小于 4096 |

状态：0=未采集，1=配置，2=采集中，3=停止/恢复，4=完整原码可读，5=失败。

原因：0=无采集错误，1=配置，2=ADC/DMA 错误，3=输出锁异常，4=超时，5=停止或恢复失败，6=计数/格式不符合要求。ADC 原码偏离名义零点不属于“DMA 采集错误”，会如实保留，不能将 READY 理解为信号质量合格。

MCU 超时为 1000 ms，与主机连接是否正常无关。DMA/ADC IRQ 不调用阻塞 HAL 停止函数、不分配内存、不调用 RTOS；清理和原码 CRC 在后台完成。CRC32/ISO-HDLC 按每对 `U低字节、U高字节、V低字节、V高字节` 计算，主机独立复算验证整个导出。

## 上板与导出工具

- `tools/adc_dma_raw_acceptance.py`：使用固定 SHA256 镜像、非活动槽、受保护 Flash 备份比较以及既有 A/B 试运行确认；不采样。
- `tools/adc_dma_raw_sample.py`：依据成功部署记录，只发一次 SAMPLE，等待 MCU 终态，导出 JSON/CSV，并验证全量 CRC、数量和前后输出锁。没有复位、刷写、清故障、重新采集或运动命令。
- 驱动板正常供电零点诊断需要电机三相线断开，12 V/0.5 A、无驱动报警的物理确认。VBUS 是 ADC 估值；协议 `PROTECT=0` 是固定字段，不是实际报警测量。

JSON 报告分别给出全部 4096 对，以及仅在统计时略去前 64 对的 4032 对；CSV/JSON 原码始终保留全部样本。范围、标准差、相邻跳变、名义值 ±100 外样本及两路同时异常，只用于诊断，不修改校准结果。

## 结果能说明什么

如果本路径也出现原码跳变，说明现象不只出现在原注入回调读取路径，但仍不能只凭这一项确定 EMI、共地、传感器参考或 ADC 配置的根因。如果本次短记录没出现异常，也不能断定问题已消失。

此前 ZERO 测试丢弃 20000 对建立期，并在偏差超标时提前结束。本诊断不做那段建立期和合格窗口筛选。两者采集长度和结束条件不同，不能直接用失败次数或极值比值声称改善比例。功率级关闭的结果也不能验收运行中的电流带宽、功率开关尖峰、过流保护或工业扭矩精度。
