# 六路信号前置版：用于推进，不是电机控制版

最新结果见 [本轮实机记录](../safety_backups/six-signal-live-20261013/RESULT.md)。当前确认的是 **A460**，B457 保留回退；没有启用桥或电机。用户已经确认六路可用，本轮不再重复采集。

这一步补齐了可部署、不可开启桥的信号夹具。`SWITCH_SIGNAL_ONLY_DIAGNOSTIC=ON` 时，桥模式请求被拒绝，SD 拉高代码不编译，`SWITCH WAVE VERIFIED` 也不能解锁。普通构建默认 OFF，原正常控制保护不变。

只允许本地单次 GUARD、OFF 和 PWM 诊断。PWM 使用三相相同的 50% 参考，20 kHz 中心对齐，DTG=0xAA（按当前时钟约 1.247 µs）；ADC 在 3600 对后停止，独立 TIM7 在 190 ms 截止。参数计算不代替电气测量。

## 不要混淆三种结果

1. **六路现场确认**：用户表示可用；本轮没有保存七通道波形供自动分析。
2. **保存数据重放**：OFF/PWM 两批在公共 C 核心的 6/4 预算下均未锁存。时间戳/角度是模拟的。
3. **真实桥/电机反馈**：SD=0 不产生真实功率开关工况。本轮没有这项结果。

中值零点通过，原码资格未通过。前两项结果不自动改变第三项的准入，也不把 A460 的观察器伪装成 B457 的实时保护绑定。

## 工具边界

- `six_signal_acceptance.py`：固定 B457 → A 的官方 UART Transfer 路径。此次被原超时锁存拒绝，未写入。
- `six_signal_swd_deploy.py`：核对故障及 Flash 未变化，受控仅写 A，再走原 bootloader 正常试运行；本轮已完成，禁止盲目重跑。
- `six_signal_capture.py`：固定 A460 的单次零点/OFF/PWM；本轮已完成，不自动复位或重复。
- `six_signal_feedback_replay.py`：仅分析保存的完整批次，执行公共 C 核心；无串口、刷写或电机操作。
- `pwm_six_channel_qualification.py`：可选七通道 `.sr` 分析。检查频率、数字信号间隙、采样到的重叠、SD 电平及相间对齐；结果始终不授权桥或电机。本轮没有输入文件，不虚构 PASS。
