# 双倍旋入转速：配置完成，性能验收未通过

本次将“提升一倍”按旋入配方速度 ×2 处理，不是所有限幅乘二，也不是将实际测得
的转速乘二。当前只完成源码、离线测试和编译；没有串口/CAN 操作、刷写、复位、
KVS 写入、故障清除或电机动作。尖峰排查按用户要求暂停，未标记解决。

## 改了什么

新增显式 `TIGHTEN_SPEED_X2_OFFLINE` 实验分支和 A/B 的 `RundownSpeedX2Offline` preset。
普通配置默认关闭该分支，原参数 ABI 与范围不变。

| 参数 | 普通配置 | 双倍离线配置 |
| --- | ---: | ---: |
| 默认旋入目标 | 80 rpm | 160 rpm |
| 旋入配方上限 | 120 rpm | 240 rpm |
| 旋入下限 | 20 rpm | 20 rpm |
| 通用速度指令上限 | 250 rpm | 250 rpm |
| 超速停机阈值 | 300 rpm | 300 rpm |
| 速度环 Iq 上限 | 0.40 A | 0.40 A |
| 直接 Iq 上限 | 0.15 A | 0.15 A |
| FOC 电压矢量限幅 | 0.80 V | 0.80 V |
| 相电流保护阈值 | 2.0 A | 2.0 A |

接触检测、后段速度/行程保护、校准门槛、故障停机、看门狗和远程动作拒绝均未放宽。
160 rpm 小于通用 250 rpm 指令上限，无需提高超速阈值。

实验 preset 只可组合硬锁定的合成测试配置；CMake 和 main.c 编译门禁拒绝可运动
普通配置混入双倍参数。该分支禁用 `TightenParams_StorageSave`，防止 >120 rpm
的实验值进入旧回退固件共用的 V1 记录；已有 KVS 记录仍原值加载，不自动翻倍。
`SyntheticTask` 使用源码默认值进行 CPU 模型运算，不使用 KVS 参数驱动真实电机。

## 验证结果

- 参数、V1 存储兼容和实验禁写主机测试：3/3 通过。
- Python 模型合同/回归测试：27/27 通过。包含提速过冲必须报告失败的测试，
  因此“测试通过”不等于“提速性能通过”。
- A/B 双倍实验和原 CanRpcReadOnly 配置均编译链接成功；存在未使用变量/函数警告，
  不宣称零警告构建。双倍实验静态 RAM 约 121 KB；编译余量不是运行时栈验收。
- A/B 普通配置显式开双倍选项均被 CMake 拒绝，负向门禁检查通过。
- 原 80 rpm 模型数值检查回归通过；仍不是工业精度或实机验收。
- **160 rpm 模型完整运行退出码为 1，不能标记通过**：硬连接的虚拟扭矩反馈候选
  单次触发 OVERTORQUE，30 次扰动中 20 次过冲退出、10 次符合模型示例要求。
- 该硬连接候选不同积分步长的最终值最大差异 2.482%，超过原数值检查 1% 门槛；
  三种步长都触发过冲，未为凑通过调整误差带或保护阈值。

这里只使用合成电机、负载与虚拟扭矩传感器。模型没有真实 EMI 尖峰、母线电压限制、
电源限流、温升或完整 dq/SVPWM，因此上述数字不能预测真实硬件安全边界。
原 MCU 合成验收的结果期望矩阵仍是旧配置，不声称新 preset 已上板通过。
