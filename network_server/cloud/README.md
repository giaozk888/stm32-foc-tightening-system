## 已知现场信息与边界

用户提供的检查输出：Ubuntu 20.04、Python 3.8.10、未安装 nginx；当次 `ss -lnt` 没有 80、443、18088 监听，存在 22、111、1883、9001、8554、8888、8889 等监听。

监听地址不等于腾讯云安全组实际放通。这里只确认该次输出，不能推断现有服务归属、长期空闲、地域或域名。禁止因为端口号猜测就停止已有服务。未 SSH 登录或对服务器作任何写入。

后端按 Python 3.8 语法兼容方式准备，无 pip 依赖、不替换 `/usr/bin/python3`。本机静态语法与当前 Python 的服务器回归通过，不等于服务器 Python 3.8 已实测。旧系统的持续安全维护须单独核对；本部署不执行系统升级。

## 第一阶段：仅通过 SSH 隧道验收后端

部署包包含 `network_server/`，不包含固件、现场密钥、数据库、合成观测截图。先上传到服务器一个新目录并解压，保留包里的 `network_server` 目录层级；所有命令从其父目录执行。

1. 在服务器只运行服务器测试（临时数据库、临时本地监听，不生成真实电机数据）：

```bash
python3 -m unittest discover -s network_server/tests -p test_server.py -v
```

必须 11 项全通过，再继续。它验证服务器、SQLite 和 HTTP 在真正 Python 3.8 上工作；不会连接 STM32/ESP32。

2. 服务器终端隐藏输入本地 token，再启动仅本机监听的后端：

```bash
read -r -s -p 'API token (24..128 printable ASCII): ' TIGHTEN_API_TOKEN
printf '\n'
export TIGHTEN_API_TOKEN
python3 -m network_server.server --bind 127.0.0.1 --port 18088
```

长随机 token 自行本地生成，不用发聊天，也不作为命令行参数。前台服务用于首次验证，不等于安装开机服务；Ctrl+C 可停止。无自动放通公网 18088。

3. Windows 新终端建立 SSH 本地转发，私钥/密码通过自己已有 SSH 客户端管理：

```powershell
ssh -N -L 127.0.0.1:18088:127.0.0.1:18088 root@118.25.40.152
```

先核对 SSH 主机指纹；不要禁用主机密钥验证。MobaXterm 也可建立等价本地隧道。浏览器访问 `http://127.0.0.1:18088/`，在本地页面输入同一个 token；空数据库显示 0 条是正常情况。HTTP 仅在本机回环上，远端传输由 SSH 加密，不是公网明文演示。

这个隧道仅用于 PC 验收页面，ESP32 不能通过 PC 本地地址上传。不要为了联网演示把真实 token 发到公网 HTTP，也不要用合成测试记录冒充实际作业。

## 第二阶段：域名 / HTTPS 与长期运行

仍需用户提供：服务器地域、有无域名及域名解析状态。证书选择、验证与必要的域名合规要求应结合实际部署核对，不能仅从公网 IP 推断。

- 建议入口 HTTPS 443 → nginx → `127.0.0.1:18088`。使用 ESP32 能验证的证书链与主机名，不能关闭证书验证；HTTPS 网关还需要可用的 DNS/SNTP。
- 安装 nginx、证书、开放腾讯云安全组和修改服务器防火墙会改变远端状态，需部署时明确执行并复查已有配置；当前没有执行，也没有提供含猜测域名的可直接启用配置。
- `tencent-observations.service` 是**未安装模板**：静态服务用户 `tightening`；程序目录 `/opt/tightening-observations`；密钥文件 `/etc/tightening-observations.env`（root 拥有、0600）；数据库由 systemd 的 StateDirectory 创建。
- 程序目录应由 root 管理且服务用户只读；不要长期用 root 直接运行应用。该服务不管理 nginx，也不会修改 MQTT、视频或已有网站。
- 配置文件只写 `TIGHTEN_API_TOKEN=...`，不将密钥提交仓库；日志不记录 Authorization 或请求体。
- nginx 公网入口需限制请求体、连接、请求速率和上游超时，并禁用记录鉴权头/密钥；Python 标准库后端只放回环，不能直接当公网生产入口。
- 公网不要开放 Modbus TCP 502、后端 18088 或原演示端口 8088。Modbus TCP 仍在设备受信局域网提供只读观测。
- 当前服务器 API 仅观测/结果归档，不上传已有 CAN Pigweed 日志或高频完整曲线；没有远程 START 接口。日志/曲线需要另行扩展协议和存储。
- 为数据库容量、备份、访问限制、设备独立密钥及密钥轮换另行规划。云上传成功不等于工业安全联锁或零丢失追溯验收。
